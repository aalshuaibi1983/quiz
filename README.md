# تحدّي العقول — بوابة المسابقات الثقافية

مسابقة ثقافية عربية بين فريقين (من عضو واحد حتى 6 أعضاء لكل فريق)، بثلاثة أوضاع: «الجولات السريعة» و«جرس السرعة» و«لوحة التحدي».

- `index.html` — صفحة المسابقة كاملة (التصميم، الأصوات، التعليمات، منطق اللعب).
- `bank.js` — بنك الأسئلة (2000 سؤال في 11 فئة، بعضها مدعوم بصور أعلام وخرائط وشعارات وألغاز إيموجي) محفوظ **مشفّرًا** (AES-256-GCM، والمفتاح مشتق من رمز الدخول بـ PBKDF2). لا يمكن قراءة الأسئلة دون رمز دخول من المالك.
- الصفحة لا تعمل إلا من النطاقات المسموح بها في `ALLOWED_HOSTS` داخل `index.html`.
- رموز الدخول **لا تُحفظ في المستودع**.

## تعديل الأسئلة أو تغيير رموز الدخول
```bash
node tools/quiz-export.mjs <الرمز-الحالي> questions.json     # فك التشفير للتعديل
node tools/quiz-build.mjs questions.json <رمز1> [رمز2 ...]    # إعادة التشفير بالرموز الجديدة
```
لا ترفع `questions.json` إلى المستودع (مستثنى في `.gitignore`).
